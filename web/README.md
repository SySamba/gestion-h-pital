# Plateforme Web — Hospitalière

Interface web pour navigateur (bureau, tablette). Idéale pour réception, admin, médecins et pharmacie.

## Lancer

```bash
npm install
npm run dev
```

→ http://localhost:5173

Le proxy Vite redirige `/api` vers le backend sur le port 3000.

## Prérequis

Le backend doit tourner : `cd ../backend && npm run dev`
